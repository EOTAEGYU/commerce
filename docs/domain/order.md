# 주문 도메인 (Order)

> **구현 상태**: 설계 예정

## 개요

주문 생성, 상태 관리, 취소를 담당합니다.

## 주문 상태 전이

```
PENDING (결제 대기)
    │
    ├── 결제 완료 → PAID (결제 완료)
    │                   │
    │                   ├── 배송 시작 → SHIPPING (배송 중)
    │                   │                   │
    │                   │                   └── 배송 완료 → DELIVERED (배송 완료)
    │                   │
    │                   └── 취소 요청 → CANCELLED (취소)
    │
    └── 결제 실패/취소 → CANCELLED (취소)
```

## 비즈니스 규칙

- 주문 시 재고를 즉시 차감한다.
- 취소 시 재고를 복원한다.
- `PAID` 이후 상태에서는 취소가 제한될 수 있다 (정책 결정 필요).
- 주문 금액 = 각 상품 가격 × 수량의 합계.
- 주문 생성 시점의 가격으로 금액을 고정한다 (이후 가격 변경 영향 없음).

## 주요 유스케이스

### 1. 주문 생성
1. 장바구니 또는 직접 선택 상품 확인
2. 재고 확인 및 차감 (OUT_OF_STOCK 예외)
3. OrderItem 스냅샷 생성 (상품명, 가격 고정)
4. Order 저장 → 상태: PENDING
5. 결제 요청 연동

### 2. 주문 취소
1. 본인 주문 확인
2. 취소 가능 상태 확인
3. 재고 복원
4. 상태 변경 → CANCELLED
