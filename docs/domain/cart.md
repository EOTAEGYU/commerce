# 장바구니 도메인 (Cart)

> **구현 상태**: 설계 예정

## 개요

로그인한 회원의 장바구니 아이템 관리를 담당합니다.

## 비즈니스 규칙

- 회원 1명당 장바구니 1개 (1:1 관계).
- 동일한 상품을 담으면 수량을 합산한다.
- 재고보다 많은 수량은 담을 수 없다.
- 장바구니 조회/수정은 본인만 가능하다.
- 주문 완료 시 장바구니 아이템을 비운다.

## 주요 유스케이스

### 1. 장바구니 조회
- 본인 장바구니 아이템 목록 + 각 상품 정보 + 총 금액 반환

### 2. 상품 추가
1. 상품 존재 여부 확인 (`PRODUCT_NOT_FOUND`)
2. 재고 확인 (`OUT_OF_STOCK`)
3. 동일 상품이면 수량 합산, 없으면 신규 추가

### 3. 수량 변경
1. 재고 확인
2. 수량 0 이하면 아이템 삭제

### 4. 아이템 삭제
- 해당 아이템 제거

## 엔티티 구조 (예정)

```
Cart (1) ──< CartItem (N)
              ├── productId
              ├── quantity
              └── price (담을 당시 가격 스냅샷)
```
