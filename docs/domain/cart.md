# 장바구니 도메인 (Cart)

> **구현 상태**: 구현 완료

## 개요

로그인한 회원의 장바구니 아이템 관리를 담당합니다.

## 비즈니스 규칙

- 회원 1명당 장바구니 1개 (1:1 관계). 없으면 첫 상품 추가 시 자동 생성.
- 동일한 옵션(productOptionId)을 담으면 수량을 합산한다.
- 재고보다 많은 수량은 담을 수 없다 (`OUT_OF_STOCK`).
- 장바구니 조회/수정은 본인만 가능하다.
- 주문 생성 완료 시 장바구니 아이템을 비운다.

## 주요 유스케이스

### 1. 장바구니 조회
- 본인 장바구니 아이템 목록 + 각 상품 정보 + 총 금액 반환
- 장바구니가 없으면 빈 응답 반환 (id=0, items=[], totalAmount=0)

### 2. 상품 추가
1. 상품/옵션 존재 여부 확인
2. 재고 확인 (기존 수량 + 추가 수량 ≤ 재고)
3. 동일 옵션이면 수량 합산, 없으면 신규 추가

### 3. 수량 변경
1. 본인 장바구니 항목인지 확인
2. 재고 확인
3. 수량 변경

### 4. 아이템 삭제
- 본인 장바구니 항목인지 확인 후 제거

## 엔티티 구조

```
Cart
├── userId (UNIQUE)
└──< CartItem (N)
        ├── productId
        ├── productOptionId   ← 사이즈/컬러 옵션
        ├── quantity
        └── price             ← 담을 당시 가격 스냅샷
```

## API 엔드포인트

| Method | URL | 인증 | 설명 |
|--------|-----|------|------|
| GET | `/api/cart` | 필요 | 장바구니 조회 |
| POST | `/api/cart/items` | 필요 | 상품 추가 |
| PUT | `/api/cart/items/{id}` | 필요 | 수량 변경 |
| DELETE | `/api/cart/items/{id}` | 필요 | 상품 제거 |

## 에러 코드

| 코드 | 발생 상황 |
|------|----------|
| `PRODUCT_NOT_FOUND` | 존재하지 않는 상품 추가 시도 |
| `PRODUCT_OPTION_NOT_FOUND` | 존재하지 않는 옵션 추가 시도 |
| `OUT_OF_STOCK` | 재고 초과 수량 추가/변경 시도 |
| `CART_ITEM_NOT_FOUND` | 없는 항목 수정/삭제 시도 |
| `CART_ITEM_NOT_OWNED` | 다른 회원의 항목 수정/삭제 시도 |
