# 카테고리 도메인 (Category)

> **구현 상태**: 설계 완료, 코드 미구현

## 개요

상품 분류를 위한 2depth 계층 카테고리 관리를 담당합니다.

## 비즈니스 규칙

- 카테고리는 대분류(parent=null)와 소분류(parent!=null) 2depth 구조.
- 카테고리 등록/수정/삭제는 `ADMIN` 권한만 가능.
- 카테고리 조회는 누구나 가능 (인증 불필요).
- 소분류가 존재하는 대분류는 삭제할 수 없다.
- 상품은 소분류 카테고리에만 속할 수 있다.

## 주요 유스케이스

### 1. 카테고리 등록
1. ADMIN 권한 확인
2. parentId가 있으면 부모 카테고리 존재 여부 확인
3. Category 저장

### 2. 전체 카테고리 트리 조회
- 대분류 목록 + 각 대분류의 소분류 목록 반환

### 3. 카테고리 삭제
1. 소분류가 있는 대분류는 삭제 불가 (`CATEGORY_HAS_CHILDREN`)
2. 해당 카테고리에 속한 상품이 있으면 삭제 불가 (`CATEGORY_IN_USE`)

## 엔티티 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| id | Long | 카테고리 ID |
| name | String | 카테고리명 |
| parent | Category? | 부모 카테고리 (null이면 대분류) |
| displayOrder | Int | 정렬 순서 |

## 에러 코드

| 코드 | HTTP | 상황 |
|------|------|------|
| `CATEGORY_NOT_FOUND` | 404 | 존재하지 않는 카테고리 |
| `CATEGORY_HAS_CHILDREN` | 409 | 소분류가 있는 대분류 삭제 시도 |
| `CATEGORY_IN_USE` | 409 | 상품이 속한 카테고리 삭제 시도 |
