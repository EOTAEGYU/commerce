# 상품 도메인 (Product)

> **구현 상태**: 설계 완료, 코드 미구현

## 개요

상품 등록, 조회, 수정, 삭제 및 재고 관리를 담당합니다.

## 비즈니스 규칙

- 상품 등록/수정/삭제는 `ADMIN` 권한을 가진 회원만 가능하다.
- 상품 조회(목록, 상세)는 누구나 가능하다 (인증 불필요).
- 재고(stock)는 0 이상이어야 한다.
- 재고 차감은 주문 시점에 Service 레이어에서 처리한다.
- 재고 부족 시 `OUT_OF_STOCK` 예외를 던진다.
- 가격(price)은 Long 타입, 원(KRW) 단위 정수.
- 다른 판매자의 상품을 수정/삭제하려 하면 `UNAUTHORIZED_PRODUCT_ACCESS` 예외.

## 주요 유스케이스

### 1. 상품 등록
1. ADMIN 권한 확인
2. 재고, 가격 유효성 검사 (0 이상)
3. Product 엔티티 저장

### 2. 상품 목록 조회
- 페이지네이션 적용 예정
- 전체 공개 (인증 불필요)

### 3. 상품 상세 조회
- 상품 ID로 단건 조회
- 없으면 `PRODUCT_NOT_FOUND` 예외

### 4. 재고 차감 (주문 연동)
1. 현재 재고 확인
2. 재고 부족 시 `OUT_OF_STOCK` 예외
3. 재고 차감 후 저장

## 엔티티 필드 (예정)

| 필드 | 타입 | 설명 |
|------|------|------|
| id | Long | 상품 ID |
| name | String | 상품명 |
| description | String? | 상품 설명 |
| price | Long | 가격 (원 단위) |
| stock | Int | 재고 수량 |
| sellerId | Long | 판매자 회원 ID |

## 에러 코드 (추가 예정)

| 코드 | HTTP | 상황 |
|------|------|------|
| `PRODUCT_NOT_FOUND` | 404 | 존재하지 않는 상품 조회 |
| `OUT_OF_STOCK` | 409 | 재고 부족 |
| `UNAUTHORIZED_PRODUCT_ACCESS` | 403 | 다른 판매자 상품 수정/삭제 시도 |
